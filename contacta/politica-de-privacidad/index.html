Política de privacidad

Información sobre el funcionamiento de esta web.

Contacto

Para consultas sobre privacidad y sobre las comunicaciones con Mago Huguini, escribe a contacto@magohuguini.com.

Los mensajes de contacto

Los campos de nombre y mensaje se utilizan en tu navegador para preparar una consulta. Esta web no guarda esos campos en una base de datos ni los envía a un servidor de formularios.

Al pulsar «Continuar en WhatsApp», el texto preparado se incorpora a un enlace de WhatsApp y se comunica a ese servicio. Al elegir «Abrir en mi correo», se entrega a la aplicación de correo que tengas configurada. En ambos casos, el envío del mensaje lo confirmas tú en la aplicación correspondiente.

Si contactas con Mago Huguini, la información que facilites se utilizará para atender tu consulta y comunicarnos contigo. Puedes solicitar información o la eliminación de tus mensajes a través del correo indicado.

Vídeos de YouTube

Las fotografías y los textos se alojan junto con la web. Los vídeos están alojados en YouTube. El reproductor solo se carga al pulsar su botón de reproducción; entonces YouTube recibe datos de conexión y puede utilizar sus propias tecnologías de almacenamiento.

Puedes pulsar «Desactivar vídeo» para retirar el reproductor de esta página. También puedes abrir el vídeo directamente en YouTube. Consulta la política de privacidad de Google.

Alojamiento y navegación

Este sitio se aloja en GitHub Pages. El proveedor de alojamiento puede tratar datos técnicos de las peticiones, como la dirección IP, para prestar y proteger el servicio. Consulta la declaración de privacidad de GitHub.

El código de esta web no incorpora herramientas de analítica ni publicidad y no guarda preferencias en cookies o almacenamiento local.

Servicios externos

Al abrir enlaces de WhatsApp, YouTube u otros servicios, se aplican sus propias políticas. Los datos que escribas en esas aplicaciones se gestionan fuera de esta web.
